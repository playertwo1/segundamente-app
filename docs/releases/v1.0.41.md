# Segunda Mente v1.0.41

## O que mudou

Motor de Insights mais rigoroso e mais barato:

- **Evidência conferida no código**: um insight só é salvo se todos os registros citados existem; na análise automática, são exigidos pelo menos dois registros diferentes.
- **Menos chamadas ao modelo**: na análise automática, se nenhuma etiqueta dos registros novos aparece em outro registro, a análise termina sem chamar o modelo. "Analisar agora" e a análise semanal não passam por essa checagem.
- **Prompt curto** próprio da análise automática; o motivo de "sem padrão" sai no idioma dos registros.
- **Lista de registros com etiquetas** no pedido ao agente; lista de insights existentes compacta (sem os dados do gráfico).
- **Insight apagado não volta**: os títulos apagados (últimos 30) são mostrados ao agente e o salvamento automático recusa o mesmo id ou título.
- **Um aviso por dia** na linha do tempo: novas descobertas do mesmo dia entram no cartão-resumo existente.
- **Análise semanal**: ao abrir o app, se passaram 7 dias desde a última e há registro novo, uma análise é enfileirada.
- Prompt longo (chat) sem linhas repetidas.
