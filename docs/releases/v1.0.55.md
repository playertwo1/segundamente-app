# Segunda Mente v1.0.55

## O que mudou

- **Widget Android v3 volta a poder ser adicionado:** na v1.0.54 o launcher recusava o widget ("não foi possível adicionar widget"), porque cinco layouts usavam `<View>` como divisória e cursor, e `RemoteViews` só aceita uma lista fechada de classes. Os `<View>` viraram `<FrameLayout>` em `widget_large.xml`, `widget_large_compact.xml`, `widget_medium.xml`, `widget_small.xml` e `widget_task_row.xml`, sem mudança visual.
- **Teste novo (`WidgetLayoutsTest.kt`):** confere que todos os layouts `widget_*` só usam tags aceitas por `RemoteViews`.

## Arquivos

- `segundamente_global_1.0.55_140.apk`: pacote `app.segundamente` (`versionName=1.0.55`, `versionCode=140`).
