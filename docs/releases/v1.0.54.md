# Segunda Mente v1.0.54

## O que mudou

- **Widget Android v3 inspirado no novo visual:**
  - **Paleta grafite e geometria concêntrica (`colors.xml`, `dimens.xml`):** fundo `#131519` com borda `#2A2E35`, superfícies internas rebaixadas `#0D0F12` / `#171A20`, teclas `#1B1E24`, texto claro `#F3EEE6` e destaque âmbar `#E99A3D`.
  - **Estado expandido (`widget_large.xml` / `widget_large_compact.xml`):** cabeçalho com o ícone real do app (`@drawable/sm_launcher_foreground`), barra de abas em cápsula (`Capturar`, `Tarefas` e `Linha do tempo`), 4 atalhos rápidos (`Falar`, `Anotar`, `Foto` e `Colar`), caixa escura com cursor âmbar (`O que você quer registrar?`), linha de ação (`+ Nova tarefa` + `Registrar →`) e cartão **Tarefas de hoje** (`Ver todas ›`) sem cortar tarefas pela metade (bolinha âmbar para atrasadas e verde para hoje). Em `250–339 dp` (`4×3`), oculta a barra de abas e combina entrada + `+ Tarefas` para preservar 1 tarefa inteira; a partir de `340 dp` abre o layout completo com 1 a 3 tarefas (`340 / 388 / 436 dp`).
  - **Estado médio (`widget_medium.xml` / `widget_medium_compact.xml`):** cabeçalho opcional (`>= 160 dp`), 4 atalhos rápidos e barra `O que você quer registrar?` com botão `Registrar →` (mantendo fallback compacto para `200×120 dp`).
  - **Estado compacto (`widget_small.xml` / `widget_small_compact.xml`):** dock `4×1` com ícone do app, faixa `Capturar | Falar | Tarefas` e botão circular âmbar `+` para nova tarefa (mantendo fallback compacto para `200×60 dp`).
  - **Roteamento e testes (`WidgetLayouts.kt`, `WidgetLayoutsTest.kt`):** preservação dos `PendingIntent`s de captura flutuante e `memex://open_todo`, adição dos novos alvos (`widget_open_app`, `widget_open_external`, `widget_open_settings`, `widget_nav_capture`, `widget_nav_tasks`, `widget_nav_timeline`, `widget_register_btn`, `widget_small_todo`) e novos testes de limiar de linhas/modo compacto (`4/4` testes passando).
