# SEGUNDA MENTE + LUMEN | PACOTE DE PLANEJAMENTO v1.0
**Data:** 12/11/2026 | **Tipo:** planejamento de produto e engenharia, NÃO implementação concluída.

## Decisão de produto
**Segunda Mente** é o aplicativo completo (Android e Windows). **Lumen**, sem acento, é o personagem/entrada compacta interativa no Windows, inspirado em recursos do Coucou. São **duas experiências que andam juntas**, distribuídas como um único produto no PC, compartilhando as mesmas anotações, tarefas, conversas, memória e personas. Ao clicar no Lumen, abre-se a ferramenta completa da Segunda Mente, com continuidade contextual. Não são dois produtos nem dois bancos de dados independentes.

## Atenção ao escopo
MVP de uso **profissional**, inicialmente com dados **fictícios ou expressamente autorizados**. Não há integração com Samsung Reminder, Hermes ou Orbit. O Coucou é referência/código a reutilizar sob revisão de licença, não um produto instalado ao lado. E-mail e controle de aplicativos Windows são pós-MVP.
