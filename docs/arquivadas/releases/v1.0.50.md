# Segunda Mente v1.0.50

## O que mudou

- **Atualizador do app sem token para repositório público (`D-067`)**:
  - `playertwo1/segundamente-app` alterado para repositório público no GitHub.
  - `AppUpdateService` passa a consultar releases e baixar APKs públicos sem exigir token ou enviar cabeçalho `Authorization`, priorizando `browser_download_url` com fallback para `asset['url']`.
  - Removidos o campo e os controles de token GitHub nas Configurações (`EarlyUpdateSettingsCard`); a checagem automática roda sem configuração de senha/token.

- Suite completa do repositório (`flutter test` integral) e `flutter analyze` integral não foram reexecutados nesta release.
- Validação física no Galaxy S25 Ultra (instalação, áudio, notificações, segundo plano e ciclo completo de autoatualização no aparelho) marcada como `NOT_RUN` — aparelho desconectado durante o build.
